# 용세 대장간 (Ember Tithe)

드래곤의 굴 앞에 사슬로 묶인 대장장이가 되어, 매일 검을 두드려 세금으로 바치는 3D 브라우저 게임입니다.
한 번 더 내려칠지, 여기서 멈출지를 고르는 강화 도박 로그라이트입니다.

**플레이:** https://kdh61313-chico.github.io/forgetax/

## 특징
- 1인칭으로 대장간을 직접 걸어 다니며 화로 · 모루 · 거치대 · 공물대 · 상인 · 유물 전시장을 오가는 구조
- 검은 +5 · +10 · … · +40 · +50 · +60 · +80 · +100마다 계속 진화 (13단계 외형)
- 숙련도 · 연타 보너스 · 단련(망치/모루/화로/거치대) 덕분에 후반엔 +100강까지 폭발적으로 성장
- 설치 없이 브라우저에서 바로 실행 (PC · 가로 화면 모바일)
- 모든 3D 모델과 질감은 코드로 생성 (외부 이미지·모델 파일 없음)
- 타격 결과 5종(대성공·성공·유지·손상·파괴), 타이밍 바, 열기, 불꽃 폭주
- 유물 18종, 특수 검 6종(+15 최종 형태 고유 스킬), 매일 바뀌는 사건 11종
- 계약 마지막 날 드래곤 '재비늘 이그나르'와 결전, 무한 모드
- 멀티플레이: 방 코드로 2~8명, 개인전 / 팀전, 저주 · 선물 · 탄원 · 이모트, 봇

## 멀티플레이 방식
서버 없이 WebRTC P2P로 연결합니다. **방을 만든 사람이 방장(서버 역할)** 이 되며, 방장이 나가면 방이 닫힙니다.
연결 중개에는 공개 PeerJS 서버를 쓰고, 회사·학교·일부 모바일 데이터처럼 P2P를 막는 네트워크에서는 연결이 안 될 수 있습니다.

직접 PeerJS 서버를 띄웠다면 주소 뒤에 `?peer=호스트:포트` 를 붙여 그 서버를 쓸 수 있습니다.

## 조작
- PC: WASD 이동 · Shift 달리기 · 마우스 드래그 시점 · E/클릭 상호작용 · Space 타격(꾹 누르면 연속) · H 가열 · G 공물 자동 선택 · B 종 · 1~6 장소로 걸어가기
- 결전: A/D 회전 · W/S 거리 · 클릭/J 공격 · Q 스킬 · Space 회피
- 모바일(가로): 왼쪽 스틱 이동 · 화면 드래그 시점 · 탭/상호작용 버튼, 결전은 조이스틱 + 버튼

## 사용한 라이브러리
- [three.js](https://threejs.org/) r128 (MIT)
- [PeerJS](https://peerjs.com/) 1.5 (MIT)

강화 로그라이트 장르에서 영감을 받은 독립 제작 게임이며, 다른 상업 게임의 에셋이나 이름을 사용하지 않습니다.
